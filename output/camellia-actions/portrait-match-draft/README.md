# Portrait-matching action drafts

Status: integrated into the website on 2026-09-13 at the user's request. The original RGB drafts are preserved. With explicit user approval, Apple Vision removed the baked-in checkerboards locally from all 48 cells; the attempted imagegen background extraction was not used.

Runtime assets: `public/camellia/{walk,pet,feed,scratch}-portrait-v1.webp`, each 12 frames, four columns × three rows, 384 × 320 pixels per cell. Care torso widths are calibrated to 140 atlas pixels using the median opaque torso span in source rows 220–250. Vertical scale stays fixed at 273/356 so head movement does not rescale the body height. Body centers and paw baselines are aligned; feeding allows 10 source pixels below the paws for the bowl. Walking uses fixed .77 scale instead of enlarging to fill the cell. Playback uses discrete frames to avoid doubled silhouettes. Pet and Scratch last 3.5 seconds; Feed lasts 5 seconds. Walking follows distance traveled; reduced motion uses a static reaction pose.

Processing: `processed/frames` contains the original row-major crops, `processed/masked` the transparent cutouts, `processed/mask.swift` the Apple Vision processor, `processed/repair-bowls.py` restores original bowl pixels in two masks, and `processed/pack.py` is the atlas packer (run from the project root). The idle image is now the first pet frame, on the identical canvas and baseline, saved as `idle-portrait-v1.webp`. Some source pose/proportion variation and imperfect fine-fur segmentation remain.

Historical diagnosis before integration:

Diagnosis: the current seated portrait was revised against IMG_2694, while action atlases were generated separately through earlier reference chains. Each action frame also has less source detail than the standalone portrait. Runtime cross-dissolves can add transient double silhouettes. A CSS brightness adjustment cannot repair identity and anatomical differences.
